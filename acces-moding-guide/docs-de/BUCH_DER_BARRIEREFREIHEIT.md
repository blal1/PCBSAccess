# Das Buch der Barrierefreiheit: Unity-Modding für blinde Spieler

Willkommen im ultimativem Leitfaden zur Erstellung von Accessibility-Mods für Unity-Spiele. Dieses Buch führt Sie von den Grundprinzipien des Moddings bis hin zum Aufbau eines anspruchsvollen, modularen Frameworks, das blinden Spielern ermöglicht, Spiele auf Augenhöhe mit sehenden Spielern zu erleben.
