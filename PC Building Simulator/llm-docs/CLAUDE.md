# LLM Documentation Overview

This directory contains synthesized documentation for PC Building Simulator to assist in modding for accessibility.

## Contents

- **game_overview.md**: High-level overview of control schemes, mechanics, and environment.
- **screens_reference.md**: Guide to the various screens and how they map to mod handlers.
- **api_reference.md**: Technical reference for singletons, input, and UI components.
- **mod_architecture.md**: Overview of the PCBSAccess mod's design and patterns.
