# PC Building Simulator: Game Overview

## 1. Control Schemes
The game uses the **Rewired** input system instead of Unity's default Input system for most game actions. Keys are rebindable by the user.

### Standard Keyboard/Mouse Bindings (Default)
- **Movement**: `WASD` (Move X/Y)
- **Camera**: Mouse movement (Look X/Y)
- **Interact / Primary Action**: `E` (Action)
- **Secondary Action**: `Q` (Secondary Action)
- **PC Power Button**: `P` (Power)
- **Inventory**: `Tab` or `I`
- **Menu / Back / Cancel**: `Escape`
- **Zoom**: Mouse Scroll Wheel
- **Camera Pan**: Middle Mouse Button
- **Camera Rotate**: Right Mouse Button
- **Run**: `Left Shift`

### Modes
- **Assembly Mode**: Toggles part installation.
- **Disassembly Mode**: Toggles part removal.
- **Cabling Mode**: Toggles cable connection view.
- **Piping Mode**: Toggles water cooling piping.

---

## 2. Space and Environment
- **Perspective**: First-person.
- **Environment**: 3D Workshop environments.
- **Interaction Model**: Raycast-based interaction with objects in the 3D space.
- **Key Objects**:
  - **Workbenches**: Where PCs are built and repaired.
  - **Storage Cabinets**: For storing parts.
  - **Delivery Area**: Where ordered parts arrive.
  - **Shop Computer**: Main interface for emails, shop, and jobs.
  - **Calendar**: For progressing time (next day).

---

## 3. Basic Mechanics
- **Building PCs**:
  - Installing parts (Motherboard, CPU, GPU, RAM, Storage, PSU, Cooling).
  - Managing screws (hold to unscrew/screw).
  - Cabling (connecting power and data cables).
- **Diagnosing Issues**:
  - Reading job descriptions.
  - Running benchmarks (3DMark).
  - Identifying broken parts (e.g., "Broken" tag in inventory).
- **Inventory Management**:
  - Buying parts from the Shop.
  - Tracking owned vs. needed parts.
- **Career Mode**:
  - **Cash**: Earned by completing jobs. Used for parts and rent.
  - **Kudos (Reputation)**: Earned through quality work. Unlocks new levels and parts.
  - **Star Rating**: Reflects customer satisfaction.
- **Shop**:
  - Browsing and ordering parts.
  - Delivery speed options (Same day, Next day, etc.).
